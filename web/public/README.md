# web/public/

Static files served as-is at the site root.

- `icons/icon.svg`: the "EC" monogram (a ring open on the right reads as C, around an E).
  Favicon and source for the PNGs.
- `icons/apple-touch-icon.png`, `icon-192.png`, `icon-512.png`: home-screen and manifest icons,
  rendered from the SVG.
- `og.png`: the 1200×630 link preview shown when a share link is pasted into Messages, Slack, etc.
- `manifest.webmanifest`: name, colors and icons for "Add to Home Screen".
